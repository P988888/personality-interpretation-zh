# 人工审阅清单

自动校验器（`scripts/validate.py`）只能拦住机器可判定的违规项。以下这些**只有人能判断**，
必须逐条过。这是数据质量的上限所在——机器保证下限，你保证上限。

审阅方式建议：把 curated 数据按 `_meta.combination` 分组，**每组至少精读 2 条**，
再随机抽 10% 通读。不必每条都逐字审，但组合覆盖必须完整。

---

## 一、致命问题（发现即淘汰，不需犹豫）

- [ ] **套模板**：把这段解读换个分数还能用吗？如果能，淘汰。这是最常见的失败模式。
- [ ] **无交互分析**：是否只是把维度逐个写了一遍，没有讲维度之间的拉扯？
- [ ] **只讲好话**：是否只讲了优势，没有讲对应的代价和盲区？
- [ ] **临床暗示**：自动校验漏掉的呢？比如「你情绪起伏比别人大，要注意调节」——
      看似无害，但已经在暗示病理。淘汰。
- [ ] **数据错误**：解读里描述的高低方向，和输入 JSON 的分数量级对得上吗？
      （例如输入神经质 22 却写成「情绪反应较强」——方向性错误，必须淘汰。）

## 二、质量问题（标记后修正，或降低采样权重）

- [ ] **facet 使用是否到位**：是否以 facet 为主要单位？只讲大维度的是外行写法。
- [ ] **中点区处理**：输入里 40–60 的 facet，是否被过度解读了？
      正确做法是明确说「区分度有限」，错误做法是硬讲出高低差异。
- [ ] **易混构念是否区分**：O3（情绪感受度）与 N（神经质）有没有被混为一谈？
      A4（合作）高 + N4（自我意识）高 的「让步-懊恼」循环有没有被点出？
- [ ] **语言是否具体**：有没有「你比较有创造力」这类空话？要求说清在什么方面、以什么方式。
- [ ] **语气是否像在对人说话**：第二人称、有温度、不文学化、不冷冰冰。
- [ ] **长度是否失控**：600–1000 字是标准，超过 1500 字通常说明在灌水。
- [ ] **结构是否模板化**：是否每段都以维度名开头，做成了填表？那种读起来很机械。

## 三、专项检查（按组合类型重点看）

| 组合类型 | 重点检查 |
|---|---|
| `spike_N` / 神经质高 | 措辞是否守住了红线？有没有滑向「情绪有问题」？ |
| `all_mid` | 是否正确承认「这份结果测不出明显倾向」，而不是硬编内容？ |
| `E2_high_E3_low` | 是否点出了「爱人群但不主导，常被误读为内向」？ |
| `C_high_N_high` | 是否点出了「高标准+高焦虑=易倦怠」这个风险组合？ |
| `A_high_N_high` | 是否点出了边界问题与事后懊恼循环？ |
| `O3_high_N_low` | 是否正确区分了「感受丰富」与「情绪反应强」？ |
| `all_high` / `all_low` | 极端分数下措辞是否仍然保持了分寸，没有夸张化？ |

## 四、审阅记录模板

对每条审阅的样本记一行，便于后续统计：

```
[样本ID] [组合类型] 判定(PASS/FIX/DROP) 问题描述(若有)
```

---

## 五、关于数据量的建议

- **不要追求数量**。1500–3000 条精选样本远胜 10000 条平庸样本。
- 你这个场景的真实约束是**审阅时间**，不是生成能力。API 生成 3000 条是几小时的事，
  但每条都认真看是不可能的。
- 因此推荐策略：**生成 2 倍于目标的量（如 5000 条），自动校验筛掉一批，
  再按组合类型分层抽样审阅，最终保留 2000 条左右**。
- 如果发现某类组合的合格率特别低，说明提示词或规格在该处有问题——
  回去改规格，而不是硬凑数据。**这是最有价值的反馈信号。**

## 六、什么时候可以停止加数据

出现以下信号时，说明数据量已够，再增加收益递减：

- [ ] 连续审阅 50 条，没有发现新的失败模式（说明已覆盖主要情况）
- [ ] 训练后验证集 loss 稳定，且抽样输出质量稳定
- [ ] 你自己看新生成的解读，已经很难说出「这条明显不行」

到这一步，把精力转到**评估**上（见 docs/eval-plan.md），而不是继续堆数据。
