# 训练监控大屏

暗色科技风的训练过程可视化。数据全部来自真实的 `fulltrain.log` 与 `nvidia-smi`，
没有任何装饰性假数据。

```
浏览器  ──HTTP──►  dashboard/server.py  ──ssh──►  remote_metrics.py  ──读──►  fulltrain.log
  (本机)              (本机 8000 端口)            (训练机上解析)              + nvidia-smi
```

## 启动

```bash
# 本机（推荐）：浏览器打开 http://127.0.0.1:8000
python3 dashboard/server.py 8000

# 局域网也能看（手机上盯着训练）
# 启动时会打印 http://<你的内网IP>:8000
```

依赖 `~/.ssh/config` 里的 `personality-gpu` 别名与免密登录（已配好），
换机器时用环境变量覆盖：`TRAIN_SSH_HOST=别的别名 python3 dashboard/server.py 8000`

## 中间那个球显示什么

大屏的核心不是"一个好看的地球"，而是**让人一眼看出训练在健康推进**。
所以球体上每一层视觉都绑定一个真实指标，越靠中心越重要：

| 视觉元素 | 绑定数据 | 怎么读 |
|---|---|---|
| **球心光核颜色** | 当前 loss | `2.8 → 1.2` 映射成色带：暗红（刚起步）→ 琥珀 → 蓝 → 青 → 白热（收敛好）。**越亮越冷 = 越好** |
| **光核脉动频率** | loss 下降速率 | 越收敛跳得越快，像被点燃的恒星。梯度范数大时会有细微抖动 |
| **赤道进度环** | `step / total` | 青色实心部分 = 已完成。环上 3 个刻度点 = 3 个 epoch 的边界，过了就点亮 |
| **外圈紫色螺旋** | loss 随进度的轨迹 | 极坐标：角度 = 训练进度，半径 = loss。**向心收缩 = 在收敛**；若向外扩 = 在发散 |
| **内流粒子** | GPU 利用率 + 吞吐 | 沿经线向球心流动的小点，代表正在被消费的训练样本。数量随 GPU 利用率变化 |
| **网格球自转** | `sec_per_it` | 转得越快说明这轮跑得越快 |
| 内/外两条紫色虚线 | loss 的映射范围 | 外圈 = `2.45`（高 loss 参考），内圈 = `1.25`（低 loss 参考） |

一句话：**球是模型本体，光核是它的"体温"，赤道环是进度，外圈螺旋是收敛轨迹。**

设计上刻意没做的事：不给球体按"大五维度"分区染色。训练日志里没有按维度拆分的 loss，
那样做只能靠编造数字——宁可不要。

## 周围面板

- **左**：训练进度 / 核心指标（loss、eval_loss、grad_norm、lr）/ 训练概况（数据构成、起始与当前 loss、降幅、超参）
- **中**：球体 + loss 收敛曲线（绿色菱形 = eval 检查点）
- **右**：GPU 状态 / 学习率调度 / 梯度范数 / 球体读数对照表
- **底**：日志流（已过滤掉 tqdm 进度条碎片，只留信息行 + 最后一条进度）

## 文件

| 文件 | 作用 |
|---|---|
| `server.py` | 本机服务端。起 HTTP，转发 ssh 请求，带 4 秒缓存 |
| `remote_metrics.py` | **跑在训练机上**。解析日志与 nvidia-smi，输出一份小 JSON |
| `index.html` | 全部前端。零外部依赖（不加载任何 CDN），图表和球体都是手写 Canvas |
| `serve_remote.py` | 备份方案：直接在训练机上起大屏，不需要 ssh |
| `start_remote.sh` | 在训练机上重启大屏 |

## 踩过的坑

1. **进度条总数不能"取第一个"**。日志前缀有数据预处理的 `4/4`，中间还有 eval 的 `40/40`。
   按出现次数投票选主进度条才对（主训练条刷新最频繁）。
2. **step 要用 epoch 反推**，不能读进度条。摘要行往往打在进度条刷新之前，会读到上一步。
   `step = round(epoch × total / epochs)` 与 progress bar 完全吻合。
3. **log 不能直接 `tail` 原始字节**。进度条用 `\r` 刷新，从中间截断会切出 `48% |` 这种碎片。
   必须按行过滤后再取尾部。
4. **`pkill -f xxx` 会匹配到同一条 ssh 命令行里后半句的 `xxx`**，等于自杀，且静默无输出。
   杀掉重启类操作要放进独立脚本里执行。
5. **球体色带的方向容易搞反**。颜色是"越亮越收敛"，不是"越亮越危险"。
   第一版把最好的一端映射成了暗红，看起来像出事。
