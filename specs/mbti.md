# MBTI 解读规格

依据：荣格《心理类型》的认知功能理论 + Myers-Briggs 四维二分框架。
**本规格的立场：以认知功能（八维）为解读主干，以四字母类型为外壳标签。**

配合 `behavior-rules.md` 使用。MBTI 部分对「认识论诚实」的要求高于大五，因为其学术地位本身有争议，见第五节。

---

## 零、总原则

1. **MBTI 是框架，不是结论。** 它描述偏好，不描述能力，不描述命运。
2. **解读主干是认知功能栈，不是四个字母。** 同为 INTJ 和 INFJ，字面只差一个字母，功能栈完全不同，不能套同一段话。
3. **字母是二分的，人是连续的。** 每个维度都有「强度」——用 51/49 分出的字母，和 90/10 分出的字母，可靠性天差地别，**必须区别对待**。
4. **每次输出都要有一句争议说明。** 可以短，不能省。

## 一、四个维度

### E / I — 能量方向
- **E（外倾）**：能量朝向外部世界，通过与人和环境的互动恢复精力；倾向边说边想。
- **I（内倾）**：能量朝向内部世界，通过独处与内在整理恢复精力；倾向想清楚再说。
- **最常见的误解**：I ≠ 害羞、社恐、不善社交。E ≠ 话多、外向开朗。这是**能量来源**的差别，不是社交能力或性格好坏的差别。大量社交能力很强的 I 型存在。**这一条在解读 I 型时必须主动澄清。**

### S / N — 信息获取
- **S（实感）**：关注具体、实际、当下的信息；信任经验和感官证据；描述细节。
- **N（直觉）**：关注模式、关联、可能性；信任联想与推断；描述图景。
- **误解**：S ≠ 笨、没想象力；N ≠ 聪明、有远见。二者是**注意力落点**差异。

### T / F — 决策方式
- **T（思维）**：以逻辑一致性与客观标准作决策依据；倾向指出问题所在。
- **F（情感）**：以价值、关系影响与人的处境作决策依据；倾向维护和谐与体谅。
- **误解**：T ≠ 无情冷酷；F ≠ 感情用事、不理性。F 的判断同样有内在标准，只是标准是价值而非逻辑。**T 型不等于不在乎人，F 型不等于不会讲道理。**
- **红线**：绝不说「T 型的人比较冷漠」「F 型的人不适合做决策」。

### J / P — 生活态度
- **J（判断）**：偏好计划、闭环、确定；事情有结论才安心。
- **P（知觉）**：偏好开放、灵活、保留选项；过早定死会不适。
- **误解**：J ≠ 死板；P ≠ 拖延懒惰。这是对**结构与开放**的偏好差异。

## 二、八种认知功能

四大功能 × 两个态度 = 八个功能。功能栈（function stack）是解读的核心。

| 功能 | 名称 | 核心运作 |
|---|---|---|
| **Ni** | 内倾直觉 | 向内收敛，形成对事物走向的整体洞察与深层模式把握；常有「就是会这样」的确信但难以解释过程 |
| **Ne** | 外倾直觉 | 向外发散，在事物间生成新联系与可能性；擅长看到多种选项与「还能怎样」 |
| **Si** | 内倾实感 | 向内沉淀，以过往经验与熟悉细节为参照；重视稳定、传统做法、身体感受与既有印象 |
| **Se** | 外倾实感 | 向外感知，完整吸收当下的感官现实；反应快、行动力强、对环境变化敏锐 |
| **Ti** | 内倾思维 | 向内建构，追求内在逻辑体系的精确与自洽；善于发现定义漏洞与不一致 |
| **Te** | 外倾思维 | 向外组织，以效率和结果为目标组织外部资源与流程；擅长推动、规划、达成 |
| **Fi** | 内倾情感 | 向内持守，基于个人深层价值判断对错；忠于自我，不易被外部意见动摇 |
| **Fe** | 外倾情感 | 向外调谐，感知并照顾群体的情绪与关系和谐；擅长维护氛围、照顾他人需要 |

**功能栈含义**：
- **主导功能（Dominant）**：最自然、最熟练的运作方式，是人格的底色。
- **辅助功能（Auxiliary）**：支撑主导，用于平衡内外朝向。
- **第三功能（Tertiary）**：发展中，中年前后逐渐可用，常是放松时的出口。
- **劣势功能（Inferior）**：最不熟练，压力下可能失控或以笨拙方式爆发。**这是解读最能体现专业度的地方——讲劣势功能带来的压力反应。**

## 四、解读规则

### 1. 必须基于功能栈，而非字母表面
同字母组合（如 INTJ / INFJ）差异巨大，不得套用通用话术。
解读顺序：**主导功能 → 辅助功能 →（压力下的）劣势功能 → 功能之间的张力**。

### 2. 必须报告二分强度，并据此调整确信度
输入应包含每个维度的连续分数（如 E 62% / I 38%）。

- **强度接近（如 55/45 以内）**：明确说明「这个字母的区分度低，你可能两种情况都有，不必把自己固定在这一侧」。**这是专业与业余的重要分野。**
- **强度明显（如 75/25 以上）**：可以较有把握地描述该偏好。

### 3. 必须以功能解释表面行为，而不是反过来
错误写法：「你是 INFP，所以你很善良。」
正确写法：「你的主导功能 Fi 意味着你的判断以个人价值为核心，这通常表现为——当某件事触及你的价值观时，你的坚持会远超平时，且不容易被外部理由说服。」

### 4. 必须讲劣势功能与压力反应
这是最能体现专业度的部分。
- 例（INTJ，劣势 Se）：「在高压下，劣势 Se 可能以失控的方式出现——比如突然对感官刺激（吃喝、购物、刷视频）失去节制，或对当下环境细节变得极度烦躁。这是压力信号，不是你的本性。」
- 例（ENFP，劣势 Si）：「压力下劣势 Si 会表现为对身体细节和过往的过度反刍——反复回想某次说错的话，或对健康小事过度担忧。」

### 5. 不能把类型当能力标签
禁止：「INFP 适合做艺术」「ESTJ 天生是管理者」「NT 型的人智商更高」。
可以说：某种功能偏好让某类任务更省力，但不构成能力判断，也不构成职业适配结论。

### 6. 必须保留个体差异的余地
明确说明：同一类型内个体差异极大，且类型本身会随情境与人生阶段呈现不同面貌。**类型是地图，不是地形。**

## 五、争议说明（每份 MBTI 解读必须包含）

以平实、不攻击也不辩护的语气写 2–3 句，要点：

1. MBTI 不在主流心理测量学公认的效度体系内，其**重测信度偏低**——相当比例的人隔几个月重测会得到不同的类型（尤其二分接近时）。
2. 强制二分的做法抹掉了中间地带，而人格特质在统计上更接近**连续分布**（这正对应大五的做法）。
3. 但它作为**自我反思的语言**是有价值的——提供了一套讨论「我如何获取信息、如何决策、精力从哪来」的词汇。可以作为探索的起点，不宜作为定论。

**推荐措辞示例：**
> 需要说明的是，MBTI 在学术心理测量学中并不被视为严格可靠的分类工具——不少人在几个月后重测会得到不同的类型，尤其当某个维度的分数接近中间时。它更适合当作一套讨论自己的语言和反思的起点，而不是关于「我是什么人」的定论。下面基于你的功能栈来谈。

**禁止的写法：**
- 为它辩护式：「虽然有些争议，但 MBTI 其实非常准确……」 → 不诚实。
- 全盘否定式：「MBTI 是伪科学，你的结果没有意义。」 → 也不专业，且无助于受测者。
- 假装中立省略：完全不提。 → 不合格。

## 六、输入格式约定

```json
{
  "instrument": "mbti",
  "result": "INFP",
  "dimensions": {
    "E": 38, "I": 62,
    "S": 31, "N": 69,
    "T": 44, "F": 56,
    "J": 47, "P": 53
  },
  "preferred_function_stack": ["Fi", "Ne", "Si", "Te"],
  "clarity": {
    "EI": "clear",
    "SN": "clear",
    "TF": "slight",
    "JP": "marginal"
  }
}
```

- `clarity` 由上游按分数差计算并传入；模型据其调整措辞确信度（见第四节规则 2）。
- **题目版权**：不得复制或近似复现 Myers-Briggs 官方题目文本。计分由上游完成。
- 若上游提供的是自编题目（如基于四维定义的开放式问卷），须在输出的局限性说明中额外声明「本测评为基于四维构念的自编量表，非官方 MBTI 工具」。

## 七、与大五的根本差异（写交叉解读时注意）

| | 大五 | MBTI |
|---|---|---|
| 底层模型 | 特质，连续 | 类型，二分 |
| 学术地位 | 主流公认 | 有争议 |
| 稳定性 | 较高 | 重测信度偏低 |
| 解读单位 | facet 组合 | 认知功能栈 |
| 可否报百分位 | 有常模时可行 | 不做同类比较 |

**关键纪律：两套量表的结果不能互相验证或映射。** 没有可靠的 MBTI→大五 转换关系。若受测者同时做了两套，应当**分别解读**，若两者看起来矛盾（如大五外向性低但测出 E），应说明这正体现了自陈测题框架与二分框架的差异，而不是判定哪一套「测错了」。
