# 大五人格 (Big Five / Five-Factor Model) 解读规格

依据：Costa & McCrae 的 NEO-PI-R 五因素模型框架 + IPIP (International Personality Item Pool, ipip.ori.org) 公共领域量表。
IPIP-NEO-120 / IPIP-NEO-300 的结构与本规格一致：5 个大维度，每维 6 个 facet，共 30 个 facet。

适用约束：本文件配合 `behavior-rules.md` 使用，所有输出必须满足行为准则。

---

## 零、给模型的总原则

1. **五个维度不是五个盒子，是一张网。** 任何解读都要先看交互，再看单项。
2. **30 个 facet 才是解读的基本单位。** 大维度分数只用于开场定调。
3. **每个 facet 都有高低两端，两端都不是好坏，是不同。** 必须两端都讲。
4. **分数是连续的。** 用「偏向」「略高」「居中」，不用「你是 X 型」。
5. 大五**没有类型**。任何把大五结果说成「你是某种人格类型」的输出都是错的。

---

## 一、五维度概览

| 维度 | 英文 | 高分核心 | 低分核心 |
|---|---|---|---|
| 开放性 | Openness to Experience (O) | 好奇、求新、想象力与审美敏感、观念开放 | 务实、传统、偏好熟悉与确定 |
| 尽责性 | Conscientiousness (C) | 有序、自律、目标导向、可靠 | 随性、灵活、不喜约束 |
| 外向性 | Extraversion (E) | 从社交获得能量、主动、活跃、寻求刺激 | 安静、独处恢复、低刺激偏好 |
| 宜人性 | Agreeableness (A) | 信任、利他、合作、避免冲突 | 直接、批判、竞争、自我优先 |
| 神经质 | Neuroticism (N) | 情绪反应强烈、易感受压力与负性情绪 | 情绪稳定、抗压、不易波动 |

**重要措辞纪律：**
- N 维度**不说**「情绪不稳定」，说「情绪反应更敏锐/更强烈，对压力更敏感」。
- A 低**不说**「自私/冷漠」，说「更直接、更看重自己的判断、不回避冲突」。
- C 低**不说**「懒」，说「不依赖计划和秩序，更随性灵活」。
- O 低**不说**「保守落后」，说「看重实际与经验，对未经验证的新事物更审慎」。

---

## 二、30 个 Facet 详解

每项含：定义 / 高分解读要点 / 低分解读要点 / 常见组合张力。

---

### 开放性 (Openness, O)

#### O1 想象力 (Imagination)
- **定义**：愿意进入幻想与内在意象世界，思维活跃、画面感强。
- **高**：内在世界丰富，常在心里预演场景、构想可能性；容易被故事、隐喻、假设吸引。代价是可能沉在设想里，对当下的现实关注不足。
- **低**：思维贴着现实走，偏好具体、可验证的事；不爱空想，处理问题时直接看手头有什么。代价是可能错过不显然的可能性。
- **张力**：O1 高 + C 低 → 想法很多但落不了地；O1 高 + C 高 → 能把构想变成可执行的方案，是很强的组合。

#### O2 审美 (Artistic Interests)
- **定义**：对艺术、音乐、自然之美与形式感的敏感与投入。
- **高**：容易被氛围、比例、质感、旋律打动；对环境和物品的美感有要求。这常表现为对空间、穿着、作品细节的在意。
- **低**：不太被形式美感牵动，更关注功能与实用。不觉得「好看」本身是理由。
- **张力**：O2 高 + O5（观念）低 → 审美敏感但观念务实，是「感受先行、立场保守」的少见组合，容易被误读。

#### O3 情绪性/感受丰富度 (Emotionality / Feelings)
- **定义**：对自身情绪状态的觉察与重视程度，愿意让感受参与判断。
- **高**：清楚自己的情绪，重视感受的起伏，把情绪当作重要信息来源。容易被触动。
- **低**：不太关注情绪层面，倾向用理性和事实处理问题，觉得情绪是干扰项。
- **注意**：此 facet 高**不等于**神经质高。O3 是**觉察与重视**，N 是**反应强度**。O3 高 + N 低 = 感受丰富但稳；O3 高 + N 高 = 感受丰富且易被淹没。**这是必须区分的重点，混淆即为不合格。**
- **张力**：与 A 的交互明显——O3 高 + A 高 更易共情他人情绪。

#### O4 尝新/行动开放 (Adventurousness / Actions)
- **定义**：愿意尝试新活动、新地方、新做法、新体验。
- **高**：主动寻找没做过的事，旅行、新饮食、新路线、新方法都愿意试；对重复的日常容易厌倦。
- **低**：偏好熟悉的方式和已知的路径，觉得重复带来效率和安心；不主动打破惯例。
- **张力**：O4 高 + C 高 = 有纪律地探索，较均衡；O4 高 + C 低 = 兴趣广而散；O4 低 + E 高 = 爱社交但不爱新鲜，偏好熟悉的人和环境。

#### O5 观念开放 (Intellectual Curiosity / Ideas)
- **定义**：愿意接触抽象观念、参与思辨、检验既有立场。
- **高**：喜欢讨论概念、理论、可能性；愿意被论证说服而改变立场；享受「想清楚一件事」本身。
- **低**：更看重经验与结论，觉得抽象讨论空转；立场不易被言语改变，要看到实际证据。
- **张力**：O5 高 + A 低 = 爱辩论、爱挑战，容易被感受为咄咄逼人；O5 低 + O2 高 = 审美张力强但观念务实。

#### O6 价值开放 (Liberalism / Values)
- **定义**：对既有价值观、规范、传统权威的态度开放性。
- **高**：倾向质疑既定规范，认为价值标准可以被重新讨论；对多元生活方式接受度高。
- **低**：看重传统、秩序与经过时间检验的做法；认为有些标准不应当被轻易动摇。
- **措辞纪律**：**绝不用政治标签**（不说「自由派/保守派」）。只描述对规范与传统的态度倾向。这是红线。

### 尽责性 (Conscientiousness, C)

#### C1 胜任感/自我效能 (Self-Efficacy)
- **定义**：对自己能有效完成事务的信心。
- **高**：相信自己能把事情做成，面对任务有掌控感；遇阻时倾向「我再试试」。
- **低**：常怀疑自己能否搞定，面对复杂任务容易先感到吃力；更依赖外部确认。
- **张力**：C1 低 + N 高 = 自我怀疑叠加情绪敏感，是最需要温和措辞的组合；C1 高 + A 低 = 强势自信。

#### C2 秩序 (Orderliness)
- **定义**：对条理、组织、整洁与流程的偏好。
- **高**：物品、日程、文件、思路都有结构；杂乱会带来真实的不适。喜欢清单和分类。
- **低**：能在混乱中找到东西，觉得过度整理是浪费时间；桌面和思路都可以是散开的。
- **张力**：C2 高 + O1 高 = 有序地做有想象力的事；C2 低 + C3 高 = 想做得多但环境乱，效率受牵制。

#### C3 尽职/成就追求 (Dutifulness / Achievement-Striving)
- **定义**：对责任、承诺、达成目标的投入程度。
- **高**：答应的事会做到，对目标有驱动力，未完成的事会挂在心上。容易工作过量。
- **低**：不把目标压力扛在身上，更能接受「差不多就行」；不容易被未完成的事困住。
- **张力**：C3 高 + N 高 = 高投入 + 高焦虑，易倦怠，是需要点明的风险组合；C3 低 + O4 高 = 爱体验不爱成就，活得丰富但可能缺乏积累。

#### C4 条理/成就动机与自律 (Achievement Striving)
- **定义**：追求卓越、设定高标准的倾向。（IPIP 中与 C3 邻近，注意区分：C3 偏责任履行，C4 偏追求优异。）
- **高**：标准高，想做得比别人好，对自己有要求。代价是难以满足，容易自我苛责。
- **低**：不和他人比高低，满足于够用；压力小，但可能错过靠自我要求推动的成长。
- **张力**：C4 高 + C1 低 = 想做好却不信自己能做好，是内耗型组合，要讲清楚。

#### C5 自律 (Self-Discipline)
- **定义**：能推动自己开始并坚持做该做的事。
- **高**：能克服惰性，任务推进不依赖外部催促；能忍受枯燥的中间过程。
- **低**：启动需要外部结构（截止期、伙伴、环境），容易拖到最后；在有兴趣时效率反而极高。
- **张力**：C5 低 + C3 高 = 「在意责任但启动难」，常伴随自我责备；C5 低 + O4 高 = 靠新鲜感驱动。
- **措辞**：不说「拖延症」，说「启动更依赖外部结构或兴趣」。

#### C6 审慎 (Cautiousness / Deliberation)
- **定义**：行动前的思考与风险考量程度。
- **高**：行动前先想后果，不轻易下决定；很少因冲动后悔。
- **低**：倾向于先做再调整，相信边做边学；决策快，但可能承担不必要的风险。
- **张力**：C6 高 + O4 低 = 极稳健，决策慢但稳；C6 低 + E 高 + N 低 = 冒险型，行动力强。

### 外向性 (Extraversion, E)

#### E1 友善/热情 (Warmth / Friendliness)
- **定义**：对他人主动的亲近与善意。
- **高**：容易对人产生好感并表达出来，让陌生人感到被欢迎。
- **低**：不主动释放热情，对人的好感需要时间建立；不是冷漠，是慢热。
- **张力**：E1 高 + A 低 = 待人和气但立场强硬，容易让人误判；E1 低 + A 高 = 不热情但很愿意帮人。

#### E2 乐群性 (Gregariousness)
- **定义**：喜欢与他人共处、人群陪伴的程度。
- **高**：喜欢有人在场，独处久了会觉得空；社交场合是能量来源。
- **低**：偏好独处或小范围深交，人多会消耗；不是社交能力差，是需求低。
- **张力**：E2 高 + E3 低 = 喜欢人群但不愿主导；E2 低 + O5 高 = 独处想问题最舒服。

#### E3 自信果断/支配性 (Assertiveness)
- **定义**：在群体中主动表达、主导、推动的倾向。
- **高**：习惯发言、拿主意、推动事情；在群体里自然成为主导者。
- **低**：更愿意参与而非牵头，不喜欢压过别人；有想法也可能不说。
- **张力**：**E2/E1 高 + E3 低 是极常见的组合**——喜欢人、待人和善，但不主导场面，适合做支持者而不是领导者。这个组合最容易被外行误读为「内向」。
- **张力**：E3 高 + A 低 = 强势且不让步，冲突风险高。

#### E4 活跃/活力 (Activity Level)
- **定义**：行为与生活节奏的快慢、精力充沛程度。
- **高**：节奏快，闲不下来，喜欢同时推进多件事。
- **低**：节奏慢，喜欢从容，一次做一件事；快节奏会让人疲惫。
- **张力**：E4 高 + C5 低 = 忙但未必有条理；E4 低 + C6 高 = 稳缓、深思熟虑。

#### E5 寻求刺激 (Excitement-Seeking)
- **定义**：对高强度刺激、兴奋感的需求。
- **高**：喜欢兴奋、热闹、有刺激感的环境，容易对平淡感到无聊。
- **低**：偏好平静，热闹久了想撤；不需要高刺激也能满足。
- **张力**：E5 高 + C6 低 = 高风险偏好，要提醒代价；E5 低 + O4 低 = 极偏好稳定环境。

#### E6 积极情绪 (Cheerfulness / Positive Emotions)
- **定义**：体验与表达愉悦、乐观情绪的倾向。
- **高**：容易开心、爱笑、乐观，情绪基调偏亮。
- **低**：情绪基调平缓，不常表现兴奋；不是不快乐，是不外显。
- **注意**：E6 低 **不等于** 抑郁倾向。这是必须守住的边界，**绝不可**把 E6 低解读成情绪问题。
- **张力**：E6 高 + N 高 = 情绪起伏大，喜悦和低落都强烈，这是很真实的组合。

### 宜人性 (Agreeableness, A)

#### A1 信任 (Trust)
- **定义**：默认相信他人善意与诚实的倾向。
- **高**：先假定对方是善意的，容易建立关系，不容易设防。
- **低**：倾向怀疑动机，需要证据才建立信任；不容易被骗，但可能错失合作。
- **张力**：A1 高 + N 高 = 信任但敏感，容易在关系里反复受伤；A1 低 + C6 高 = 谨慎而有据。

#### A2 坦诚/直率 (Straightforwardness / Morality)
- **定义**：在人际中直接表达真实想法、不使用策略性表达的倾向。
- **高**：有话直说，不喜欢绕弯子和场面话；容易被认为单纯或天真。
- **低**：懂得场合与话术，会衡量怎么说更有利；显得世故、老练。
- **措辞**：A2 低**不说**「虚伪」，说「更擅长运用社交策略、更看重表达的效果」。
- **张力**：A2 高 + A1 高 = 坦率信任，容易被利用；A2 低 + O5 高 = 会辩论懂策略。

#### A3 利他 (Altruism)
- **定义**：主动帮助他人、为他人付出的意愿。
- **高**：看到需要就想帮，帮人会让自己舒服；容易揽下别人的事。
- **低**：先顾自己，帮人有明确的条件和限度；不是坏，是不轻易透支自己。
- **张力**：A3 高 + E3 低 + C3 高 = 老好人组合，最需要提醒边界问题。

#### A4 合作/顺从 (Compliance / Cooperation)
- **定义**：在冲突中让步、配合他人、避免对抗的倾向。
- **高**：倾向妥协，能让就让，不喜欢正面冲突。代价是可能长期压抑自己的需求。
- **低**：坚持自己的立场，该争就争；不怕冲突，甚至觉得把话说开更好。
- **张力**：**A4 高 + N 高 是必须点明的组合**——容易让步又容易事后懊恼，反复陷入「当时为什么不说」的循环。
- **张力**：A4 低 + E3 高 = 主导且强硬；A4 低 + O5 高 = 爱争论。

#### A5 谦逊 (Modesty)
- **定义**：不自夸、不把自己置于他人之上的倾向。
- **高**：不主动谈自己的成绩，觉得自我推销不自在；可能低估自己。
- **低**：愿意承认并展示自己的优势，觉得该有的认可应该拿；在竞争中不隐藏实力。
- **措辞**：A5 低**不说**「自大」，说「不回避展现自己、对自我价值有明确认知」。

#### A6 同理心/温情 (Sympathy / Tender-Mindedness)
- **定义**：对他人的处境与情绪产生关切与共鸣的倾向。
- **高**：容易被别人的困难触动，做决定时会考虑对人的影响。
- **低**：决策更看重事实与效率，不容易被他人情绪打动；显得冷静甚至冷硬。
- **张力**：A6 高 + C6 低 = 心软且冲动，容易被求助牵着走；A6 低 + O5 高 = 理性分析型。

---

### 神经质 (Neuroticism, N)

> **全局措辞纪律**：N 维度全程禁止临床词汇。只描述「情绪反应强度」「对压力的敏感度」「负性情绪的持续时间」，不描述「症状」「障碍」「稳定性问题」。
>
> **facet 学名的使用规则（实测教训）**：本文件中的 facet 名称（如「N1 焦虑」「N3 忧郁」）
> 是**给写作者看的标签**，不是给受测者看的措辞。解读正文中**禁止直接使用这些学名**，
> 尤其是 N1「焦虑」与 N3「抑郁」——读者会把它们理解成临床含义。
> 必须改用右列的描述性说法：
>
> | 学名（仅内部使用） | 解读正文中应写 |
> |---|---|
> | N1 焦虑 | 担忧倾向 / 容易提前担心 |
> | N3 忧郁 | 情绪低落的时候 / 容易被挫败感影响 |
> | N2 愤怒 | 容易烦躁 / 情绪上来得快 |
> | N5 冲动 | 对即时满足的抵抗力偏低 |
> | N6 脆弱 | 压力下容易感到不堪重负 |
>
> 同理，正文中不写「O1 想象力」这类编码，直接说「想象力」。

#### N1 焦虑 (Anxiety) — 正文中称为「担忧倾向」
- **定义**：体验担忧、紧张、预期性不安的倾向。
- **高**：容易提前担心，脑子里常放着「万一」；面对不确定会不安。
- **低**：不容易担心，对不确定能安然处之；可能因此准备不足。
- **措辞**：不说「焦虑症」，也不说「焦虑」。说「容易提前担忧、对不确定性较敏感」。

#### N2 愤怒/易激惹 (Anger / Hostility)
- **定义**：体验愤怒、烦躁与被冒犯感的倾向。
- **高**：容易被激怒，遇到不公会强烈反应；情绪上来快。
- **低**：不容易发火，被冒犯时倾向消化或忽略。
- **张力**：N2 高 + A4 低 = 直接冲突型；N2 高 + A4 高 = 生气但压着，更需点出「积压」的代价。

#### N3 忧郁 (Depression)
- **定义**：体验低落、无力、自我贬低情绪的倾向。
- **高**：情绪低谷来得较频繁，容易自我怀疑、感到泄气。
- **低**：情绪基调不易下沉，遇到挫折能较快恢复。
- **措辞红线**：**此 facet 名称本身含临床联想，输出时严禁使用「抑郁」二字。** 只能说「容易有情绪低落的时候」「容易被挫败感影响」。若受测者主动表达持续痛苦，按 behavior-rules 转介建议，不做解读。
- **张力**：N3 高 + E6 低 = 情绪基调偏低，需要尤其温和的措辞；N3 高 + C1 低 = 自我怀疑加重。

#### N4 社交不安/自我意识 (Self-Consciousness)
- **定义**：在他人注视下感到不自在、担心被评价的倾向。
- **高**：在意别人怎么看自己，容易在人群中感到被审视；事后反复回想自己的表现。
- **低**：不太在意他人评价，在人群中自在。
- **张力**：**N4 高 + E2 高 是关键组合**——想和人在一起，又怕被评价，社交是既渴望又耗损的。必须讲清这个矛盾。
- **张力**：N4 高 + E3 低 = 在群体中不发声且事后懊恼。

#### N5 冲动 (Immoderation / Impulsiveness)
- **定义**：难以抵抗欲望与即时诱惑的倾向。
- **高**：想要就难忍，容易在吃、买、玩、拖延上失控；事后可能后悔。
- **低**：能抵住即时诱惑，不易被欲望牵着走。
- **措辞**：不说「成瘾倾向」，说「对即时满足的抵抗力偏低」。
- **张力**：N5 高 + C5 低 = 双重拖累，启动难且易被打断；N5 高 + C6 低 = 冲动决策。

#### N6 脆弱/压力敏感 (Vulnerability)
- **定义**：在压力下容易感到不堪重负、失去应对能力的倾向。
- **高**：压力积累到一定程度会明显扛不住，需要恢复时间；多任务或高压环境消耗大。
- **低**：压力下仍能保持功能，不容易被压垮。
- **张力**：N6 高 + C3 高 = 责任感强但承压有限，是最需要提醒「设置负荷上限」的组合。
- **张力**：N6 高 + E4 低 + O4 低 = 偏好低刺激稳定生活，这是适应性的选择而非缺点。
